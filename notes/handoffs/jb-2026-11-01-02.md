## Key gotchas / durable lessons

- **Postman/API testing:** use `http://localhost:8000/<route>` or `http://localhost:5173/api/<route>`. `localhost:5173/topics` returns the app's HTML, not an error. Auth is `Authorization: Bearer <API_PASSWORD>` on everything except `/health`.
- **Topic filter values are exact labels** from `/topics`, including the `·`. A label that doesn't match gives no error: no excerpts, so a general answer.
- **The backend server doesn't auto-reload.** Prompt or API changes need the user to restart `study-assistant-api`; Vite picks up frontend changes on its own.
- **Seeing the UI without paid calls:** run the real `build_api` with `FakeLLM` on another port and point Vite at it with `VITE_API_TARGET`. Vite binds `localhost`, not `127.0.0.1`. Headless Chrome via `playwright-core` with `channel: "chrome"` works without a browser download. Keep such scripts in the scratchpad. Check phone-width screenshots: they caught a real bug (sticky composer hiding the newest answer).
- **`sample()` is a random-vector query** with a pool of 50, because Pinecone has no random read. Measured 98 distinct chunks from 59 files in 100 draws, so the bias is acceptable.
- **Model adapters lock around inference**, since FastAPI routes run in a thread pool. Requests queue per model: 4 concurrent retrievals took about 30 s. Don't remove the locks.
- **Quiz is stateless:** the reference answer goes to the browser with the question, hidden until graded. It's fine for one trusted user; revisit if that changes.
- **Her name:** left off the sign-in page because that page will be public, but `STUDENT_NAME` is in the public JS bundle. The backend prompts also name her; keep the user's Beverly/AFPA wording when editing them.
- **Ask before paid calls** (Bedrock tests, real `/ask`, `/quiz`). Still applies from #01, along with: the shell exports root `AWS_PROFILE`/`AWS_REGION`, so the app reads `BEDROCK_*` instead.
