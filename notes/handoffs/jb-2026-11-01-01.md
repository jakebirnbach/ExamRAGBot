## Key gotchas / durable lessons

- **Shell AWS variables:** the user's shell exports `AWS_PROFILE=default` (root) and `AWS_REGION=us-east-2`. The app reads **`BEDROCK_AWS_PROFILE` / `BEDROCK_REGION`** for that reason; never rename them back to `AWS_*`. Pass `--profile exam-rag-bot --region us-east-1` explicitly in CLI checks.
- **The Anthropic SDK Bedrock endpoint reports any access problem as `404 model does not exist`.** Use a CLI `aws bedrock-runtime converse` call to see the real `AccessDeniedException`. Denied calls aren't billed.
- **Ask the user before paid calls** (Bedrock smoke tests, `ask` runs). They have approved them when asked.
- **Eval misses are often labelling errors** (transcript speech-to-text spellings like `pre -contemplation`, `kcal/g`). Read what was retrieved before reporting a miss.
- **The user edited the system prompt** in `answer_question.py` to name the student ("Beverly") and the course provider ("AFPA"). Preserve their wording.
- mypy's first run after dependency changes takes minutes (boto3/anthropic stubs); cached runs take about 1 s. Don't mistake it for a hang.
- Model loads make every fresh CLI process slow (about 10–25 s cold; `ask` takes about 9–12 s warm). Run long jobs (ingest about 18 min, eval about 9.5 min) in the background.
- `.env` lines with blank values (`KEY=`) mean "use the default" for the Bedrock settings (validator).
- Course materials in `data/raw/` are private: never commit or publish their text.
